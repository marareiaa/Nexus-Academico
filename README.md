# Nexus Acadêmico
Sistema de Gestão de Eventos e Ligas Acadêmicas (Foco no ODS 8 - Trabalho Decente e Crescimento Econômico)  Arquitetura desenhada para gerenciar a organização de eventos, workshops ou consultorias juniores, facilitando o controle de participantes e a emissão de dados para certificados.
